# Halaman Prediksi Suhu Cuaca 🌤️

Halaman web statis untuk menampilkan prediksi suhu/cuaca berbasis HTML dan CSS sederhana. Proyek ini dibuat sebagai tugas pembelajaran atau demo untuk menampilkan antarmuka prediksi cuaca yang responsif.

## 📌 Tentang

Proyek ini berisi halaman web statis yang menampilkan prediksi suhu/cuaca (misalnya untuk kota tertentu). Halaman ini hanya menggunakan **HTML & CSS** (tanpa backend atau server prediksi nyata), sehingga cocok untuk:

* Tugas kuliah / pembelajaran
* Landing page
* Dasar pengembangan antarmuka cuaca
* Demo sederhana prediksi suhu

📂 Repositori ini mayoritas terdiri dari file HTML (100% HTML menurut statistik GitHub) yang mengatur tampilan antarmuka pengguna. ([GitHub][1])

## ⭐ Fitur

✅ Halaman prediksi suhu/cuaca berbasis HTML
✅ Tampilan antarmuka sederhana dan rapi
✅ Menggunakan *style.css* untuk tata letak dan estetika
✅ Siap dikembangkan lebih lanjut dengan JavaScript atau API cuaca nyata

## 📁 Struktur Proyek

```
Halaman-Prediksi-suhu-cuaca/
├── index.html         ← Halaman utama prediksi cuaca
├── style.css          ← Gaya dan tata letak halaman
└── (opsional) assets/ ← Gambar, ikon, atau sumber statis lain
```


## 🛠️ Pengembangan Lebih Lanjut

Untuk menjadikan halaman ini fungsional secara nyata, pertimbangkan:

* Menambahkan **JavaScript** untuk memanggil API prediksi cuaca (mis. OpenWeatherMap)
* Menggunakan **fetch()** untuk menampilkan data cuaca real-time
* Menambahkan ikon cuaca interaktif
* Membuat versi **responsif** untuk tampilan mobile
